# 小鹏免费充电站

把「哪些小鹏站能用免费权益、哪些免停车费」这件事，做成了两份可以直接用的东西：

- **用法一 · 三层地图**：一个网页，按「附近 / 全城 / 沿路线」三个层级看站，手机上也能用，还能一键把途经点发到高德导航
- **用法二 · 导入高德小程序**：导出成高德能吃的表格，导进高德 App 变成自己的图层，导航、顺路规划都在高德里完成

数据是抓来的真实数据，不是演示：

| 项 | 数值 |
|---|---|
| 覆盖 | **308 个城市**，**5179 个站** |
| 其中 | 自营免费权益 3944 · 第三方合作 1235 |
| 有停车优惠 | 3685 |
| 高速服务区站 | 36 |
| 字段完整度 | 地址 100%、价格 99.4%、桩数 98.2% |

# 用法一：三层地图

打开网页，按「附近的 / 本城市的 / 某条线路沿路的」三个层级看站。

## 打开

**在线**：<https://emfox.github.io/xiaopeng-site/>

**本地**：

```bash
python3 build.py                 # 生成 index.html + data.json(.gz) + split/
python3 -m http.server 8000      # 在仓库根目录起服务
# 浏览器打开 http://localhost:8000/
```

> 必须由 http 服务提供，`fetch` 读数据受同源限制，直接双击 `index.html` 会提示起服务。
> 想临时换一份数据集，地址栏加 `?data=别的.json` 即可。

手机上打开会自动切成底部面板布局，面板占下方约 58%，地图会把路线和站点顶到上方可见区。

## ① 附近

自动定位当前位置，默认看 **5 km** 内的站。虚线圆是距离圈，可切 3 / 5 / 10 / 20 km 或不限。

拒绝定位权限也不影响用，会用城市中心代替，之后拖动地图点「以地图中心为起点」即可。

## ② 全城

**省份 → 城市 → 区县** 三级下拉。308 个城市平铺在一层里没法找，先按省份收一层；省份按地理大区排（华北、东北、华东…），城市按站数从多到少排。

- 区县下拉带站数，如 `萧山区（21）`；只有一个区县的城市不显示这个下拉
- 列表按离市中心远近排序
- 定位成功后会自动切到你所在的城市
- 上次选的城市会记住，下次打开还是它
- 首次进入默认落在**站点最多的城市**，不是列表第一个

区县是从站点地址里反推的（接口只给 cityCode，没有区县字段），预处理结果放在 `data/districts.json`，页面按需加载。`add_meta.py` 负责生成，加了城市之后重跑一次即可。

## ③ 沿路线

选起点和终点，自动套用**高德真实驾车路线**（走真实高速，不是两点连线），然后：

- **默认给出 3 个推荐停靠站**——按里程把全程均分三段，每段挑「离高速最近 + 有停车优惠 + 自营」的那个
- 拖**行程进度条**，看开到某一段时附近有哪些站
- 点底部按钮，**一键把 3 个站作为途经点发到高德 App**，手机上直接唤起高德导航

已内置 9 条真实路线：杭州⇄上海、杭州→宁波、上海→苏州、上海→南京、上海→宁波、苏州→杭州、北京→天津、广州→深圳。

## 通用筛选

三个层级都能叠加勾选：`小鹏免费权益` / `第三方合作` / `仅看免费停车`。

# 用法二：导入高德 App（地图小程序）

把站导成高德能吃的表格，变成 App 里自己的图层。适合开车时用。

高德 App 里有个官方入口吃自定义点位：**地图小程序**。导入后点位就在高德 App 本体里，能一键导航、顺路规划，不是网页。

## 导出

```bash
python3 export_amap.py                    # 每个城市一个 xlsx → amap/
python3 export_amap.py --all              # 额外生成全国合一的大文件
python3 export_amap.py --cities 上海,杭州   # 只要这几个城市
python3 export_amap.py --park-only        # 只要带停车优惠的
python3 export_amap.py --keyword 服务区    # 按站名/地址筛选，比如只导高速服务区
```

## 导入

1. 电脑浏览器打开 <https://wia.amap.com>，登录高德账号
2. 左上「我加入的」→ **创建新地图**，起个名字（如「小鹏免费站」）
3. 顶部 **批量导入** → 数据来源选 **高德地图** → 上传 `amap/上海.xlsx`
4. 手机高德 App → 我的 → **地图小程序** → 就能看到，可一键导航

## 颜色含义

颜色填官方「颜色说明」里的第 n 个色块：

| 编号 | 色值 | 含义 | 数量 |
|---|---|---|---|
| 8 | #FF6968 红 | 免费权益 + 有停车优惠 | 3475 |
| 1 | #7E97FF 浅蓝紫 | 免费权益、无停车优惠 | 469 |
| 5 | #FFBF00 琥珀 | 第三方 + 有停车优惠 | 210 |
| 3 | #4CC7FF 天蓝 | 第三方、无停车优惠 | 1025 |

## 列格式（踩过的坑）

导出脚本**直接填充高德官方模板**（`templates/导入模板.xlsx`，已入库），不自己造 xlsx。模板 9 列：

```
名称 | *经度 | *纬度 | *地址 | 颜色 | 图标(外轮廓) | 图标(填充物) | 描述 | 文件夹
```

| 坑 | 后果 |
|---|---|
| 经纬度合成一列 `"121.17,30.89"` | 报「不支持的文件格式」 |
| 用 `.csv` 而不是 `.xlsx` | 同上报错 |
| 经纬度写成数字而非字符串 | 模板里是 `'113.681'` 字符串，跟着用 |

> 官方模板里塞了 4 张说明截图（约 1.9 MB），导出时删掉了，
> 文件从 1.9 MB 降到 7 KB～340 KB，导入更快。

## 限制

- **单城市最多 224 个站**，远低于高德 50000 行上限，所以一个城市一个文件最省事
- 高德**不支持覆盖更新**：数据变了要新建一张地图重新导，旧地图手动删
- 单次上传 ≤ 50000 行、≤ 20 MB
- 坐标系是 GCJ-02，和高德一致，**不用转换**

## 为什么不用别的路子

| 路子 | 能不能进高德 App | 说明 |
|---|---|---|
| **地图小程序**（上面这个） | ✅ 能 | 官方、免费、支持批量导入，唯一实用的路子 |
| GeoHUB 数据中心 | ❌ 不能 | 官方产品，但只面向开发者，配 JS API / 自建 App 用 |
| 高德 App「添加图层」粘贴 KML 链接 | ❌ 没这功能 | 网上有这个教程，但 App 里找不到入口 |
| DIY 地图 | ❌ 不行 | 能手动标点，上限 16 个 |
| KML 直接导入 App | ❌ 不支持 | App 没有 KML 导入入口 |

# 数据获取

数据是从小鹏官网公开页面抓的，脚本都在仓库里，可重跑、可增量。

## 数据从哪来

| 项 | 说明 |
|---|---|
| 数据源 | 小鹏官网「免费·专享」页面 `static.xiaopeng.com/apps/charge-web/pc-free-stations.html` |
| 接口 | `chargegateway.xiaopeng.com` 的 `queryMapCityLabeling`（按城市列站）+ `queryStationDtl`（站点详情） |
| 需要登录 | **不需要**，公开网页接口 |
| 坐标 | GCJ-02，与高德一致 |
| 字段 | 站名、坐标、省市区地址、快充/慢充/S4 桩数、电费+服务费、免费权益、停车优惠 |

这比高德上的小鹏站全，是因为高德只拿到 POI 坐标，而「免费权益」「停车优惠」两个字段只有小鹏自己的数据里有。

## 为什么能覆盖全国 308 城

最初只覆盖 49 个城市，因为城市清单是**手工维护**的，漏了大量地级市。最典型的漏网例子是京港澳高速的**信阳服务区**和**许昌服务区**——这两个城市压根没在清单里，所以查都没查。

小鹏的按城市查站接口只认「高德 cityCode」（**电话区号**，杭州是 `0571`，不是行政区划代码 `330100`），而 cityCode 在高德那边要靠逆地理编码从经纬度换出来，没有现成的城市清单接口。

现在的做法：

```bash
python3 discover_cities.py     # 扫描全部可能的区号，找出真正有站的城市 → data/city_codes.json
python3 fetch_nationwide.py    # 按区号抓列表 → 抓详情 → 从地址反推城市名 → 写入 data/stations/
```

`discover_cities.py` 枚举 `010`、`02X`、`0300~0999` 共 710 个候选区号，逐个探一遍，约 1 分钟，结果缓存，之后不用再扫。目前扫出 **313 个有站城市**，归并成 308 个城市名。

> 城市名不是接口给的，是从站点详情的地址里反推的（`河南省信阳市浉河区…` → `信阳`），
> 每个区号下所有站点的地址投票决定。直辖市、自治区、自治州都做了处理。

补齐后高速服务区站从 8 个变成 36 个，例如：

| 城市 | 站点 | 价格 | 停车优惠 |
|---|---|---|---|
| 信阳 | 京港澳高速信阳服务区（北京方向） | 0.73+0.72 | 有 |
| 信阳 | 京港澳高速信阳服务区（广州方向） | 0.73+0.87 | 有 |
| 许昌 | 京港澳高速许昌服务区（北京方向） | 0.73+0.88 | 有 |
| 许昌 | 京港澳高速许昌服务区（广州方向） | 0.73+0.61 | 有 |
| 鹤壁 | 京港澳高速鹤壁服务区（北京方向） | 0.73+0.86 | 有 |

## 增量更新

数据**按城市拆开存**，`data/stations/杭州.json` 就是一个文件一个城市。日常只刷你关心的那几个，不用重抓全国。

```bash
python3 fetch_xpeng.py --cities 杭州,上海 --with-detail   # 只刷这几个（约 10 秒/城）
python3 fetch_xpeng.py --stale 30 --with-detail           # 只刷超过 30 天没更新的
python3 fetch_xpeng.py --with-detail                      # 全量（约 15 分钟）
python3 build.py                                          # 重新打包（秒级）
```

> **只刷列表不会丢详情**：不带 `--with-detail` 时，地址/价格/停车优惠这些旧值会自动保留，
> 只更新站名、坐标、桩数。可以「先快速刷列表，详情慢慢补」。

加新路线：

```bash
python3 get_route.py --from-city 杭州 --to-city 苏州
# 自动写入 data/routes/杭州→苏州.json
```

## 同址重复站的处理

小鹏把同一个物理站登记成了两个 id。比如河源「中国石化创益充电站」，两条记录坐标完全一致，
一条运营方写「库仑」、一条写「中国石化」，桩数还不一样（14 vs 16）。

按 id 去重挡不住这种情况，导入高德会看到两个重叠图钉。现在按「**站名 + 坐标**」归并：
取信息最全的那条当骨架，其余记录只用来补空字段。5179 这个数字是归并后的。

## 省份和区县怎么来的

接口只给 cityCode（电话区号），**没有省份、也没有区县**。页面上要做省市两级筛选、按区县细分，只能从地址里反推：

```bash
python3 add_meta.py          # 写回 data/cities.json 的 province 字段 + 生成 data/districts.json
python3 add_meta.py --check  # 只看统计
```

- **省份**：地址一般带省名（`浙江省杭州市…`），直辖市城市名就是省名。整城地址都没写省名的（`三明三元区火车站停车场`），用同城其他站投票，再不行查 `CITY_PROVINCE_FALLBACK` 兜底
- **区县**：先剥掉「省 + 地级市」，再抓第一个 `xx区/xx县/xx市/xx旗`

区县这块之前有个 bug：老逻辑是在地址**开头**抓「2~4 个汉字 + 区/县/市」，抓出来的是「杭州市」——
于是杭州凭 10 条以「杭州市」开头的地址就凭空多出一个区县选项，选了还是全城。现在区县只从预处理结果读，
抽到市级地名的一律丢弃，上海还额外处理了 `市辖区`、`大鹏新区` 这类非标准写法。

## 目录结构：源数据 vs 构建产物

两者严格分开。根目录的 `index.html` / `data.json` 是 `build.py` 生成的**发布快照**，不要手工改。

```
data/                          源数据  ← 唯一源头
├── cities.json                308 个城市的中心点 + 区号 + 站数 + 省份
├── meta.json                  各城市站数 + 最后更新时间
├── city_codes.json            区号探测结果（discover_cities.py 生成）
├── city_meta.json             城市名 → 区号
├── districts.json             城市 → 区县清单（add_meta.py 生成）
├── stations/
│   ├── 杭州.json              一个城市一个文件 ← 增量更新只动这里
│   └── ...  (308 个)
└── routes/
    ├── 杭州→上海.json          一条真实驾车路线
    └── ...  (9 条)

index.html                     41 KB   构建产物
data.json                     1.8 MB   构建产物
data.json.gz                  387 KB   构建产物（页面优先用它）
data/districts.json            38 KB   构建产物（页面按需加载）
split/                        407 KB   构建产物
├── index.json                         城市索引，首屏先加载这个
└── 杭州.json.gz                        按城市分包，单城约 1 KB
```

产物是确定性的：内容没变就不重写文件，重跑 `build.py` 不会产生 git diff。

# 其它事项

## 已知限制

1. **接口是网页版的内部接口**，小鹏改版就可能失效。失效时 `fetch_xpeng.py` 会报错，重新从页面抓一次请求路径，改脚本里那两个 path 即可。
2. **只有「免费权益」站**。想看全部小鹏合作站（不免费的），要换 `filterCriteriaCodeList` 参数，可以再加。
3. **页面用的是高德官方页面前端 Key**，能用但不保证长期有效。长期用建议去[高德开放平台](https://console.amap.com/dev/key/app)申请自己的 JS API Key，然后 `export AMAP_JS_KEY=你的key`。
4. **停车优惠**是小鹏标注的「有停车优惠」，具体免几小时、是否限车型，到站后看现场说明或小鹏 App 站点详情。
5. **路线是城市中心到城市中心的驾车路线**。要从具体地址出发，用 `get_route.py --from 坐标 --to 坐标` 重算。
6. **区号扫描不等于全量覆盖**。308 城是「用区号能探到站」的城市，如果看到某个站没收录，把站名发来，反查它归哪个区号，补一行候选即可。

## 页面性能

5179 个点，如果一次全画上去页面会卡死。实际做法：

- 首屏只加载 `split/index.json`（城市索引），选中城市后再拉那一个城市的分包
- 图钉按当前视野裁剪，拖动/缩放过程中不重算，停下来才渲染，视觉上同时存在的点通常几十到两百个
- 数据走 gzip，`data.json.gz` 387 KB，本地解压比拉 1.8 MB 明文快

## 目录里不常改的东西

- `templates/导入模板.xlsx` —— 高德官方模板，`export_amap.py` 依赖它，别删
- `amap/` —— 导出目录，`.gitignore` 已排除
- `data/_bycode/` —— 全国抓取的原始中间件，可重跑，已排除
- `data/detail_cache/` —— 详情缓存，可重跑，已排除
