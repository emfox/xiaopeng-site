# 小鹏充电地图 → 高德地图：数据链路与工具

> 目标：把「小鹏 App 里有、高德上没有」的两类信息 —— **自营/免费权益、停车优惠** —— 叠加到你日常用的高德地图上，并且能直接用于长途路线规划。

---

## 一、先说结论

| 你想做的事 | 可行性 | 推荐做法 |
|---|---|---|
| 官方开放 API 直接拿小鹏充电站数据 | ❌ 不存在公开接口 | 小鹏未开放充电站 POI 接口，只有 App / 车机内部接口 |
| 抓包逆向 App 接口 | ⚠️ 技术上能做 | 只适合**极低频、小范围**自用（见第三节风险与合规） |
| 把站点数据导入高德 App | ✅ 可行 | 高德「我的 → 收藏 → 导入」支持表格批量导入（名称+地址），导入后自动打点 |
| 高德 App 里直接看到「免费/停车优惠」标记 | ⚠️ 只能间接 | 高德不允许第三方往它的充电图层写字段；但可以：①用名称前缀（`【鹏免费】`）让它在搜索结果里一眼可辨；②用下面的离线地图页 |
| 沿长途路线自动挑免费站并一键导航 | ✅ 可行 | 高德 URI 支持 `vian/vialons/vialats/vianames` 多途经点，直接唤起 App |
| 自己做一个「充电站 + 权益」专用地图 | ✅ 推荐 | 本目录的 `xpeng2amap.py` 生成 HTML 页 + Excel + KML |

**最省事、也最可持续的组合是：**
1. 一个月跑一次数据（抓包或手动整理）→ 2. `xpeng2amap.py` 生成台账 → 3. 台账里的「自营/免费」子表导入高德收藏夹 → 4. 长途出行用生成的 `amapuri://` 链接一键把 2~3 个免费站塞进途经点。

## 二、数据从哪来（按代价从低到高）

### 方案 A：半自动「人工巡检」（零风险，推荐起步）
- 小鹏 App 充电地图按城市 → 筛选「免费/专享」→ 逐屏截图/导出。
- 只维护你最常走的 3~5 条线路沿线（通常 50~150 个站），一两个月更新一次即可。
- 缺点：慢，但数据准确性由官方界面保证。

### 方案 B：抓包自家 App（可自动化，注意边界）
技术路线（针对 Android）：
1. 手机装 **HTTP Toolkit** 或 PC 端 **mitmproxy**；App 走系统代理 + 安装用户 CA 证书。
2. 小鹏 App 大概率有证书固定（SSL Pinning），需要用 **Frida** + `frida-multiple-unpinning` 脚本绕过（需 root 或重打包）。
3. 在 `充电地图` 页面拖动地图触发瓦片/POI 请求，抓取形如 `/charging/station/list` 的接口，记录 `Authorization`、`sign`、时间戳等签名参数。
4. 签名参数通常由 `md5(参数+盐)` 生成，可在 Frida hook 处直接拿到明文。
5. 用 Python 复现请求，按网格（如 0.1°×0.1°）遍历，落库去重。

**必须守住的边界：**
- 只抓**你自己账号可见**的公开站点信息，不碰用户数据、订单、支付接口。
- 严格限速（≤ 1 请求/秒），不做全量爬取、不做二次分发或商用。
- 这类接口是私有的、随时会变，代码大概率几周就失效 —— 把它当作「一次性导出工具」，不要当作长期依赖的产品基建。
- 如果你要做成给别人用的服务，走**小鹏开放平台/商务合作**申请数据授权才是正路。

### 方案 C：用公开数据反推（完全合规，覆盖率大概 60~70%）
1. **高德 POI 搜索**（`types=011100` 充电站 + `keywords=小鹏`，需免费申请 Web 服务 Key）—— 能拿到小鹏自营站在高德的 `poiid` 和精确坐标，但**没有权益字段**：
   ```
   https://restapi.amap.com/v3/place/text?key=KEY&types=011100&keywords=小鹏&city=310000&citylimit=true&offset=25&page=1&extensions=base
   ```
   注意单次查询最多翻到 200 条，全国范围要按城市 / 行政区（`adcode`）分别查。
2. **运营商侧数据**：小鹏三方合作站大多是 特来电 / 星星 / 国网 / 云快充 / 小桔，这些家有公开的开放平台（如特来电开放平台、星星充电开放平台），可查到桩数/功率/价格。
3. **小鹏官方公开页**：官网「充电服务」页、App 内 H5 活动页、以及社区（bbs.xiaopeng.com）里用户整理的站点清单。
4. 把 1+2+3 三份数据用「坐标 500m 内 + 名称相似度」做实体对齐，得到一张带权益标记的表。

## 三、怎么「标注到高德」

高德有四个不同层级的入口，能力依次递减：

| 层级 | 能做 | 不能做 |
|---|---|---|
| **① 高德 URI / App 内** | 单点标注、多途经点导航、收藏夹 | 不能自定义图标/字段 |
| **② 高德 JS API 网页** | 任意图标、筛选、信息窗、续航圈、路线叠加 | 需要浏览器打开，不是原生 App |
| **③ 高德「我的地图/自定义图层」** | 自己画的点线面上传 | 已大幅收紧，普通账号入口不稳定 |
| **④ 高德 App「充电站」图层** | 官方数据 | **完全不接受第三方数据写入**，这也是为什么你在高德里看不到权益信息 |

所以现实的做法是 **①+②**：

- **日常查附近** → 用 Excel「收藏夹导入用」sheet 导入高德，站点名统一加前缀：
  `【鹏免费·停】小鹏超充·虹桥天地` / `【三方】特来电·人民广场`
  这样在高德搜索「小鹏」时，前缀就是最直观的权益标签。
- **长途规划** → 生成的 `高德链接.txt` 里有 `amapuri://route/plan/?...&vian=3&vialons=...`，手机点开直接进高德导航，2~3 个免费站已设为途经点（高德手机端途经点上限约 3 个，正好够一次补能）。
- **想看全局分布** → 打开 `充电站地图.html`（本目录已生成演示版），高德底图 + 绿/蓝双色标记 + 橙色停车优惠角标 + 续航圈，点任一点可跳转高德。

## 四、附带的工具：`xpeng2amap.py`

```bash
# 1. 用内置演示数据先跑一遍看效果
python3 xpeng2amap.py --self-test --range 80 --zoom 10 --outdir demo

# 2. 用你自己的数据（支持 csv / json / xlsx，表头中英文都认；demo/站点清单.csv 是模板）
python3 xpeng2amap.py --input demo/站点清单.csv --center 121.4737,31.2304 --range 150 --zoom 11

# 3. 带路线：自动在沿线每 1/N 段挑一个免费站作为途经点
python3 xpeng2amap.py --input demo/站点清单.csv --route route.json --stops 3 --range 150
```

**输入表头**（中英文均可，顺序无所谓）：

| 站点名称 | 经度 | 纬度 | 权益类型 | 停车优惠 | 桩数 | 功率 | 价格 | 地址 |
|---|---|---|---|---|---|---|---|---|
| 小鹏超充·虹桥天地 | 121.3178 | 31.1952 | 自营/免费 | 是 | 12 | 480kW | 1.45 元/度 | 闵行区申长路688号 |

**输出：**

| 文件 | 用途 |
|---|---|
| `小鹏充电站台账.xlsx` | 全量台账，含「距中心距离」「高德链接」；第二个 sheet 是只含自营站的收藏夹导入格式 |
| `充电站地图.html` | 离线高德地图页，双色标记 + 停车优惠角标 + 续航圈 + 路线停靠建议 |
| `小鹏充电站.kml` | 通用交换格式，可导入奥维互动地图 / Google Earth / QGIS |
| `高德链接.txt` | 最近 12 个自营站的 `uri.amap.com` 单点链接 + 高德 App 多途经点导航链接 |

> ⚠️ HTML 页面使用了高德官方页面里自带的前端 Key（免注册即可出图）。**如果要正式长期使用**，请到 [高德开放平台](https://console.amap.com/dev/key/app) 申请自己的「Web 端(JS API)」Key，用环境变量注入：
> `export AMAP_JS_KEY=你的key`，再运行脚本。

## 五、坐标系：最容易踩的坑

| 坐标系 | 用在哪 |
|---|---|
| **GCJ-02（火星坐标）** | 高德、腾讯、小鹏 App 地图、大多数充电 App |
| **WGS-84** | GPS 原始输出、Google Earth、部分开放数据 |

- 高德 URI/JS API 默认按 **GCJ-02** 解释；如果数据来自 GPS 轨迹或海外地图，必须先用 `coord-convert` / `eviltransform` 转换，否则会整体偏移 300~500 米。
- 小鹏 App 显示的就是 GCJ-02，从 App 里抄出来的坐标可以直接用。

## 六、我的建议（如果只做一件事）

**把「权益」当成搜索关键词，而不是地图图层。**

高德不会让你改它的充电图层，但在小鹏 App 里能看到的筛选（免费/专享/停车优惠），你可以用**站点名前缀**固化成高德里的「自带标签」。一次导入，长期可用，零维护成本。

只有当你需要「沿线判断哪个免费站最顺路」时，再打开 `充电站地图.html` 或点 `amapuri://` 链接 —— 这才是高德官方能力覆盖不到、值得自己造轮子的部分。
