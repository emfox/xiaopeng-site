**一句话**：打开一个网页，分三层看小鹏的免费权益站和免费停车站——附近的、全城的、某条线路沿路的。

|---|---|

## 怎么用

### 打开页面

**方式一（推荐）：起个本地服务**

```bash
python3 build.py                    # 重新生成 index.html + data.json(.gz) + split/
python3 -m http.server 8000         # 在仓库根目录起服务
# 浏览器打开 http://localhost:8000/
```

**方式二：在线访问**
`https://emfox.github.io/xiaopeng-site/`

手机上打开会自动切换成底部面板布局。

> 页面必须由 http 服务提供（`fetch` 读数据受同源限制），直接双击 `index.html` 会提示起服务。
> 临时换一份数据集，地址栏加参数即可：`...?data=别的.json`

### ① 附近
自动定位你当前位置，默认 **5 km** 内的站。虚线圆 = 距离圈，可选 3/5/10/20 km 或不限。
> 浏览器会问定位权限，拒绝的话用城市中心代替，不影响使用。

### ② 全城
选城市（下拉里有 308 个），看全市所有站，再按区县细分。列表按离市中心远近排序。
> 定位成功后会自动切到你所在的城市，不用手动选。

### ③ 沿路线
选起点和终点城市，自动套用**高德真实驾车路线**（走真实高速，不是直线），然后：
- **默认给出 3 个推荐停靠站**——按里程把全程均分三段，每段挑「离高速最近 + 有停车优惠 + 自营」的那个
- 拖下面的**行程进度条**，看开到某一段时附近有哪些站
- 点底部按钮，**一键把 3 个站作为途经点发到高德 App**（手机上会直接唤起高德导航）

已内置 9 条真实路线：杭州⇄上海、上海→苏州、上海→南京、上海→宁波、北京→天津、广州→深圳、杭州→宁波、苏州→杭州。

> **手机端**：面板占下方约 58%，地图会自动把路线/站点顶到上方可见区，不会被面板压住。

三个层级都可以叠加筛选：`小鹏免费权益` / `第三方合作` / `仅看免费停车`。

## 更新数据（增量，只动变化的那部分）

数据是**按城市拆开存的**，`data/stations/杭州.json` 就是一个文件一个城市。
所以日常更新只改你关心的那几个城市，不用重抓全国。

```bash
# 只刷某几个城市（约 10 秒/城）
python3 fetch_xpeng.py --cities 杭州,上海 --with-detail

# 自动找出超过 30 天没更新的城市，只刷它们
python3 fetch_xpeng.py --stale 30 --with-detail

# 全量刷一遍（约 15 分钟）
python3 fetch_xpeng.py --with-detail

# 重新打包成网页（秒级）
python3 build.py
```

> **只刷列表不会丢详情**：不带 `--with-detail` 时，地址/价格/停车优惠这些旧值会自动保留，
> 只更新站名、坐标、桩数。所以可以「先快速刷一遍列表，详情慢慢补」。

加新路线：
```bash
python3 get_route.py --from-city 杭州 --to-city 苏州
# 自动写入 data/routes/杭州→苏州.json
```

## 目录结构：源数据 vs 构建产物

这两者严格分开，`dist/` 全部是 `build.py` 生成的，**不手工改、不入库**。

```
data/                          源数据（人工/脚本维护，入 git）  ← 唯一源头
├── cities.json                308 个城市的中心点 + 区号
├── meta.json                  各城市站数 + 最后更新时间
├── stations/
│   ├── 杭州.json              一个城市一个文件 ← 增量更新只动这里
│   ├── 上海.json
│   └── ...  (44 个)
└── routes/
    ├── 杭州→上海.json          一条真实驾车路线
    └── ...  (9 条)

index.html                     40 KB  构建产物
data.json                     1.3 MB  构建产物
data.json.gz                  261 KB  构建产物（页面优先用它）
split/                       516 KB  构建产物
├── index.json                       城市索引，首屏先加载这个
└── 杭州.json.gz                      按城市分包，单城约 5 KB
```

上层三个文件是 `build.py` 从 `data/` 生成的**发布快照**，因为 GitHub Pages 只能从仓库某个目录直接发布，
所以它们必须留在根目录并入库；但**不要手工改**，改完 `data/` 重跑 `build.py` 即可覆盖。

只有一个源头 `data/`。之前 `data/stations.json`、根目录 `data.json`、`out/data.json`
是同一份数据的三个副本（共 4 MB），现在已删除，产物随构建重生成。

## 代码分工

| 文件 | 作用 |
|---|---|
| `store.py` | 源数据读写层，所有脚本都通过它，保证结构一致 |
| `build.py` | 源数据 → 根目录发布快照（页面 + 全量包 + 城市分包），含数据校验 |
| `fetch_xpeng.py` | 采集站点，按城市落盘，支持 `--cities` / `--stale` 增量 |

| `get_route.py` | 取高德真实驾车路线（免 key） |
| `migrate_source.py` | 一次性迁移脚本（把旧的单个大 json 拆成按城市） |
| `push_github.py` | 用 GitHub REST API 同步到远端（没有代理、`git push` 不通时的兜底） |
| `template.html` | 页面模板 |

## 推送：为什么要挂代理

沙箱里 `github.com:443` 的写操作（`git push`）会被拦，只有 `api.github.com` 通。所以最早是 `push_github.py` 走 REST API 手工造 blob → tree → commit。

能开代理就直接用 git：

```bash
./proxy.sh start          # 起 mihomo，HTTP/SOCKS 混合端口 7890
git push                  # 全局配置里 github.com 已指向 7890，直接推
```

REST API 那条路 648 个文件要逐个 POST，5 分钟只能传 500 个；走代理是一次 pack，几秒钟的事。**有代理就别用 `push_github.py`。**

> 首次推送曾因远端历史是 API 造的链（commit sha 和本地不一致）被拒。确认远端那些提交都是同一个脚本生成的之后，用 `--force-with-lease` 覆盖，历史就统一成本地这条线了。

## 已知限制

1. **接口是网页版的内部接口**，小鹏改版就可能失效。失效时 `fetch_xpeng.py` 会报错，重新从页面抓一次请求路径，改脚本里那两个 path 即可。
2. **只有「免费权益」站**。如果想看全部小鹏合作站（不免费的），要换 `filterCriteriaCodeList` 参数，可以再加。
3. **页面用的是高德官方页面前端 Key**，能用但不保证长期有效。长期用建议去[高德开放平台](https://console.amap.com/dev/key/app)申请自己的 JS API Key，然后 `export AMAP_JS_KEY=你的key`。
4. **停车优惠**是小鹏标注的「有停车优惠」，具体免几小时、是否限车型，到站后看现场说明或小鹏 App 站点详情。
5. **路线是城市中心到城市中心的驾车路线**。要从具体地址出发，用 `get_route.py --from 坐标 --to 坐标` 重算。

## 导入高德 App（地图小程序）

高德 App 里有一个官方入口可以直接吃自定义点位：**地图小程序**。导入后点位就在高德 App 本体里，能一键导航、顺路规划，不是网页。

### 怎么导

```bash
python3 export_amap.py          # 每个城市一个 xlsx → amap/
python3 export_amap.py --all    # 额外生成全国合一的文件
python3 export_amap.py --cities 上海,杭州
python3 export_amap.py --park-only   # 只要带停车优惠的
```

1. 电脑浏览器打开 <https://wia.amap.com>，登录高德账号
2. 左上「我加入的」→ **创建新地图**，起个名字（如「小鹏免费站」）
3. 顶部 **批量导入** → 数据来源选 **高德地图** → 上传 `amap/上海.xlsx`
4. 手机高德 App → 我的 → **地图小程序** → 就能看到，可一键导航

### 颜色含义

颜色填官方「颜色说明」里的第 n 个色块：

| 编号 | 色值 | 含义 | 全国数量 |
|---|---|---|---|
| 8 | #FF6968 红 | 免费权益 + 有停车优惠 | 2508 |
| 1 | #7E97FF 浅蓝紫 | 免费权益、无停车优惠 | 333 |
| 5 | #FFBF00 琥珀 | 第三方 + 有停车优惠 | 135 |
| 3 | #4CC7FF 天蓝 | 第三方、无停车优惠 | 373 |

### 列格式（踩过的坑）

> **已实测通过**：2026-10-23 用「汕头.xlsx」(14 站) 在 wia.amap.com 批量导入成功。
> 当前导出逻辑是有效的，别轻易改动表头和单元格类型。

导出脚本**直接填充高德官方模板**（`templates/导入模板.xlsx`，已入库），不自己造 xlsx。
官方模板 9 列：

```
名称 | *经度 | *纬度 | *地址 | 颜色 | 图标(外轮廓) | 图标(填充物) | 描述 | 文件夹
```

踩过的三个坑：

| 坑 | 后果 |
|---|---|
| 经纬度合成一列 `"121.17,30.89"` | 报「不支持的文件格式」 |
| 用 `.csv` 而不是 `.xlsx` | 同上报错 |
| 经纬度写成数字而非字符串 | 模板里是 `'113.681'` 字符串，跟着用 |

> 官方模板里塞了 4 张说明截图（约 1.9 MB），导出时删掉了，
> 文件从 1.9 MB 降到 7 KB～340 KB，导入更快。

### 限制

- **单个城市最多 224 个站**，远低于高德 50000 行的上限，所以一个城市一个文件最省事
- 高德目前**不支持覆盖更新**：数据变了要新建一张地图重新导，旧地图手动删
- 单次上传 ≤ 50000 行、≤ 20 MB
- 坐标系是 GCJ-02，和高德一致，**不用转换**（小鹏数据本身就是 GCJ-02）

### 为什么不用别的路子

| 路子 | 能不能进高德 App | 说明 |
|---|---|---|
| **地图小程序**（上面这个） | ✅ 能 | 官方、免费、支持批量导入，唯一实用的路子 |
| GeoHUB 数据中心 | ❌ 不能 | 官方产品，但只面向开发者，配 JS API / 自建 App 用 |
| 高德 App「添加图层」粘贴 KML 链接 | ❌ 没这功能 | 网上有这个教程，但高德 App 里找不到入口，不可信 |
| DIY 地图 | ❌ 不行 | 官方功能但只能手动标点，上限 16 个 |
| KML 直接导入 App | ❌ 不支持 | 高德 App 没有 KML 导入入口 |

## 为什么能覆盖全国 308 城（以及高速服务区）

之前只覆盖 49 个城市，是因为城市清单是**手工维护**的，漏了大量地级市。最典型的漏网例子是
京港澳高速的**信阳服务区**和**许昌服务区**——这两个城市压根没在清单里，所以查都没查。

小鹏的按城市查站接口只认「高德 cityCode」（电话区号，如杭州 `0571`），而 cityCode 在高德那边
要靠逆地理编码从经纬度换出来，没有现成的城市清单接口。现在的做法：

```bash
python3 discover_cities.py     # 扫描全部可能的区号，找出真正有站的城市 → data/city_codes.json
python3 fetch_nationwide.py    # 按区号抓列表 → 抓详情 → 从地址反推城市名 → 写入 data/stations/
```

`discover_cities.py` 会枚举 `010`、`02X`、`0300~0999` 共 710 个候选区号，逐个探一遍，
约 1 分钟，结果缓存下来，之后不用再扫。目前扫出 **313 个有站城市**，归并成 308 个城市名。

> 城市名不是接口给的，是从站点详情的地址里反推的（`河南省信阳市浉河区…` → `信阳`），
> 每个区号下所有站点的地址投票决定。直辖市、自治区、自治州的边缘情况都做了处理。
